# Supply-Chain-Strategy-Dashboard
a beginners project in logistics.
## Blok 4: Supply Chain Strategy Dashboard

Narzędzie łączące analizę efektu bicza, decyzje make-or-buy, 
lokalizację magazynu metodą środka ciężkości oraz dopasowanie 
strategii zapasów (bufor vs JIT) do kategorii produktu (ABC).

Kluczowy wniosek: strategia zarządzania zapasami powinna być 
zróżnicowana w zależności od wartości i przewidywalności 
popytu na dany produkt, a nie jednolita dla całego asortymentu.
